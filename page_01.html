GitHub LFS 推送方法

Large File Storage 大檔案管理

安裝與設定

1 安裝 Git LFS
git lfs install
2 追蹤大檔案類型（例如：圖片、影片、模型檔）
git lfs track "*.psd"
git lfs track "*.mp4"
git lfs track "*.zip"

推送流程

3 確認 .gitattributes 已被追蹤
git add .gitattributes
4 加入大檔案
git add your-large-file.psd
5 提交變更
git commit -m "Add large files via LFS"
6 推送到 GitHub
git push origin main
提醒：使用 git lfs ls-files 可查看已被 LFS 追蹤的檔案清單
